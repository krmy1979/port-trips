# נגלות נמל – מדריך התקנה

אפליקציה שסופרת כמה רכבים כל נהג הוציא מהאונייה לחניה, לפי מיקום GPS, ומחשבת פרמיה לכל נהג.

## מה יש בתיקייה

| קובץ | מה הוא עושה |
|---|---|
| `index.html` | האפליקציה עצמה (מסך נהג ומסך מנהל) |
| `config.js` | **הקובץ היחיד שצריך לערוך**: החיבור ל-Firebase |
| `firestore.rules` | חוקי אבטחה למסד הנתונים |
| `manifest.webmanifest`, `sw.js`, `icon*` | מאפשרים "הוספה למסך הבית" באייפון ועבודה גם כשהקליטה חלשה |

## לנסות מיד (בלי שרת)

מעלים את התיקייה ל-GitHub Pages (שלב 3 למטה) ופותחים את הקישור. כל עוד `firebase` ב-`config.js` הוא `null`, האפליקציה רצה ב**מצב הדגמה**: הנתונים נשמרים רק בטלפון, ואפשר לדמות נסיעה בלחיצה על המפה.

## הפעלה אמיתית (בערך 20 דקות, בחינם)

### שלב 1: יצירת Firebase
1. נכנסים ל-https://console.firebase.google.com ולוחצים **Add project**. שם לדוגמה: `port-trips`.
2. בתפריט: **Build ← Authentication ← Get started**. מפעילים שתי שיטות כניסה:
   - **Anonymous** (בשביל הנהגים, בלי סיסמה)
   - **Google** (בשביל המנהל)
3. בתפריט: **Build ← Firestore Database ← Create database**. בוחרים מיקום `eur3 (europe-west)`, במצב **production**.
4. בלשונית **Rules** של Firestore מוחקים הכל ומדביקים את התוכן של `firestore.rules`. **מחליפים את `manager@gmail.com` בכתובת ה-Gmail שלך**, ואז לוחצים **Publish**.
5. בגלגל השיניים ← **Project settings** ← למטה **Your apps** ← לוחצים על הסמל `</>` (Web). נותנים שם ולוחצים Register. מופיע קוד עם `firebaseConfig = {...}`. מעתיקים את מה שבתוך הסוגריים המסולסלים.

### שלב 2: עריכת config.js
- מדביקים את ה-config במקום `firebase: null`, כמו בדוגמה שבקובץ.
- את המנהלים לא כותבים כאן. הם מוגדרים רק בחוקים ב-Firebase (שלב 1.4), כדי שכתובת המייל לא תופיע בקוד הציבורי.

### שלב 3: העלאה ל-GitHub Pages
1. ב-GitHub יוצרים מאגר חדש, למשל `port-trips`.
2. **Add file ← Upload files** ← גוררים את כל הקבצים מהתיקייה ← **Commit**.
3. **Settings ← Pages** ← Source: `main` / `root` ← Save.
4. אחרי דקה הקישור מוכן: `https://<שם-המשתמש>.github.io/port-trips/`
5. חוזרים ל-Firebase: **Authentication ← Settings ← Authorized domains ← Add domain**, ומוסיפים את `<שם-המשתמש>.github.io`. בלי זה, כניסת המנהל עם Google לא תעבוד.

### שלב 4: הגדרת האזורים
1. נכנסים לקישור, לשונית **מנהל**, ולוחצים **כניסה עם Google**.
2. ב"הגדרות" לוחצים **הצב על המפה** ומקישים על מיקום הרציף, ואחר כך על החניה. אפשר לכוון את הרדיוס עם הסרגל.
3. קובעים פרמיה לרכב ולוחצים **שמור הגדרות**. ההגדרות עוברות אוטומטית לכל הנהגים.

## הוראות לנהגים (לשלוח בקבוצת הוואטסאפ)
1. לפתוח את הקישור ב-**Safari** באייפון או ב-**Chrome** באנדרואיד.
2. באייפון: כפתור השיתוף ← **הוספה למסך הבית**.
3. להקליד שם ומספר עובד, ללחוץ **התחל משמרת**, ולאשר גישה למיקום.
4. **להשאיר את האפליקציה פתוחה והמסך דולק כל המשמרת.**
5. בסוף העבודה ללחוץ **סיים משמרת**. מרגע זה המיקום כבר לא נשלח.

## איך נספרת נגלה
הגעה לאזור האונייה, ואחריה הגעה לאזור החניה = רכב אחד. נגלה נספרת רק אם:
- עבר לפחות "זמן מינימלי לנגלה" (ברירת מחדל: 60 שניות) בין האונייה לחניה.
- הדיוק של ה-GPS טוב מספיק (ברירת מחדל: 40 מטר).

כך קפיצות של GPS לא נספרות כרכב.

## מגבלות שחשוב לדעת
- **אייפון ומסך כבוי:** אפליקציית דפדפן לא יכולה לעקוב אחרי מיקום כשהיא סגורה או כשהמסך כבוי. האפליקציה מבקשת להשאיר את המסך דולק, אבל אם נהג נועל את הטלפון, הנגלות שלו לא ייספרו. מעקב ברקע דורש אפליקציה טבעית מחנות האפליקציות (שלב הבא, אם תרצה).
- **זיוף:** נהג עם ידע טכני יכול תיאורטית לזייף מיקום. החוקים מונעים מנהג לשנות או למחוק נגלות, ורשימת הנגלות עם השעות מאפשרת לזהות חריגות. למי שרוצה הגנה מלאה, אפשר להוסיף בעתיד סריקת ברקוד של כל רכב.
- **פרטיות:** זה מעקב מיקום של עובדים. חובה ליידע את הנהגים ולקבל את הסכמתם, ומומלץ לתאם עם הוועד. המיקום נשלח רק בזמן משמרת, ורק המנהל רואה אותו.
- **עלות:** במסלול החינמי של Firebase (Spark) יש מספיק מקום לצוות של עשרות נהגים.
